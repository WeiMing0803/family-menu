# 家庭点餐小程序 设计文档

> 版本：v1.0  
> 更新日期：2026-09-19  
> 目标用户：家庭两人（可扩展）共享菜单与点餐

---

## 1. 项目概述

### 1.1 项目目标
为家庭（两人）打造一个轻量、实时同步的点餐小程序。  
双方都可以：
- 查看 / 创建 / 编辑 / 删除菜品
- 点菜（加入今日想吃列表）
- 实时看到对方的操作

### 1.2 核心特点
- 极简操作，无复杂权限
- 实时同步（SignalR）
- 数据量小，使用 SQLite 即可
- 后端完全使用 .NET，前端使用微信原生小程序

---

## 2. 技术栈

| 层级       | 技术                          | 说明 |
|------------|-------------------------------|------|
| 前端       | 微信小程序原生 + Vant Weapp   | 官方推荐，轻量易上手 |
| 后端       | ASP.NET Core 10 Web API       | 最新 LTS，性能优秀 |
| 实时通信   | SignalR                       | 实现菜单/订单实时同步 |
| 数据库     | SQLite + Entity Framework Core 10 | 零配置、适合家庭场景 |
| 身份认证   | 微信登录（openid） + JWT      | 简单可靠 |
| 部署建议   | Oracle Cloud Always Free / 微信云托管 / 自有服务器 | 免费或低成本 |

---

## 3. 功能需求

### 3.1 用户与家庭
- 微信一键登录，获取 openid
- 创建家庭（自动生成邀请码）
- 通过邀请码加入家庭（最多支持 2 人，可后期扩展）
- 查看家庭成员

### 3.2 菜品管理（双方可操作）
- 新增菜品（名称、分类、备注、图片可选）
- 编辑 / 删除菜品
- 按分类筛选、搜索
- 标记“喜欢”或“常吃”

### 3.3 点餐功能
- 将菜品加入「今日想吃」列表
- 修改数量、添加备注
- 删除已点菜品
- 标记“已做完 / 不吃了”
- 查看历史点餐记录

### 3.4 实时同步
- 任意一方新增/修改菜品或点餐，另一方页面实时更新
- 使用 SignalR 推送

### 3.5 其他
- 简单统计（本周最常点的菜）
- 支持清空今日点餐

## 4. 系统架构

```
微信小程序
    ↓  (HTTPS + wx.request)
ASP.NET Core 10 Web API
    ├── Controllers（RESTful API）
    ├── SignalR Hub（实时推送）
    ├── Services（业务逻辑）
    └── EF Core + SQLite
```

**数据流：**
1. 用户操作 → 调用 API
2. API 处理业务 + 写入 SQLite
3. 通过 SignalR 向同家庭的其他连接推送变更
4. 前端收到推送后更新页面

## 5. 数据库设计（SQLite）

### 5.1 表结构

#### Users（用户表）
| 字段名       | 类型          | 说明 |
|--------------|---------------|------|
| Id           | INTEGER PK    | 主键 |
| OpenId       | TEXT UNIQUE   | 微信 openid |
| NickName     | TEXT          | 昵称 |
| AvatarUrl    | TEXT          | 头像 |
| FamilyId     | INTEGER       | 所属家庭（可为空） |
| CreatedAt    | DATETIME      | 创建时间 |

#### Families（家庭表）
| 字段名       | 类型          | 说明 |
|--------------|---------------|------|
| Id           | INTEGER PK    | 主键 |
| Name         | TEXT          | 家庭名称（默认“我们的家”） |
| InviteCode   | TEXT UNIQUE   | 邀请码（6位） |
| CreatedAt    | DATETIME      | 创建时间 |

#### Dishes（菜品表）
| 字段名       | 类型          | 说明 |
|--------------|---------------|------|
| Id           | INTEGER PK    | 主键 |
| FamilyId     | INTEGER       | 所属家庭 |
| Name         | TEXT          | 菜名 |
| Category     | TEXT          | 分类（早餐/午餐/晚餐/其他） |
| Remark       | TEXT          | 备注 |
| ImageUrl     | TEXT          | 图片（可选） |
| IsFavorite   | INTEGER       | 是否喜欢（0/1） |
| CreatedBy    | INTEGER       | 创建人 UserId |
| CreatedAt    | DATETIME      | 创建时间 |
| UpdatedAt    | DATETIME      | 更新时间 |

#### Orders（点餐记录表）
| 字段名       | 类型          | 说明 |
|--------------|---------------|------|
| Id           | INTEGER PK    | 主键 |
| FamilyId     | INTEGER       | 所属家庭 |
| OrderDate    | DATE          | 点餐日期（默认今天） |
| Status       | TEXT          | 状态（Active / Completed / Cancelled） |
| CreatedAt    | DATETIME      | 创建时间 |

#### OrderItems（点餐明细表）
| 字段名       | 类型          | 说明 |
|--------------|---------------|------|
| Id           | INTEGER PK    | 主键 |
| OrderId      | INTEGER       | 所属订单 |
| DishId       | INTEGER       | 菜品 |
| Quantity     | INTEGER       | 数量（默认1） |
| Remark       | TEXT          | 个人备注 |
| Status       | TEXT          | Pending / Done / Cancelled |
| AddedBy      | INTEGER       | 添加人 |
| CreatedAt    | DATETIME      | 添加时间 |

> 说明：SQLite 使用 INTEGER 表示布尔和主键，日期用 TEXT 或 DATETIME 均可。

### 5.2 索引建议
- Users.OpenId
- Families.InviteCode
- Dishes.FamilyId + Category
- Orders.FamilyId + OrderDate
- OrderItems.OrderId

## 6. API 设计（RESTful）

基础路径：`/api`

### 6.1 认证相关
| 方法 | 路径                  | 说明 |
|------|-----------------------|------|
| POST | /auth/login           | 微信登录，返回 JWT + 用户信息 |
| GET  | /auth/me              | 获取当前用户信息 |

### 6.2 家庭相关
| 方法 | 路径                  | 说明 |
|------|-----------------------|------|
| POST | /family/create        | 创建家庭 |
| POST | /family/join          | 通过邀请码加入 |
| GET  | /family                | 获取当前家庭信息 |
| GET  | /family/members        | 获取家庭成员 |

### 6.3 菜品相关
| 方法 | 路径                  | 说明 |
|------|-----------------------|------|
| GET  | /dishes               | 获取菜品列表（支持分类、搜索） |
| POST | /dishes               | 新增菜品 |
| PUT  | /dishes/{id}          | 更新菜品 |
| DELETE | /dishes/{id}        | 删除菜品 |
| PUT  | /dishes/{id}/favorite | 切换喜欢状态 |

### 6.4 点餐相关
| 方法 | 路径                        | 说明 |
|------|-----------------------------|------|
| GET  | /orders/today               | 获取今日点餐 |
| POST | /orders/items               | 添加菜品到今日点餐 |
| PUT  | /orders/items/{id}          | 修改数量/备注/状态 |
| DELETE | /orders/items/{id}        | 删除点餐项 |
| POST | /orders/clear               | 清空今日点餐 |
| GET  | /orders/history             | 历史点餐记录 |

### 6.5 SignalR Hub
- Hub 路径：`/hubs/family`
- 连接时需携带 JWT
- 客户端加入 Group：`family_{FamilyId}`
- 服务端推送事件：
  - `DishChanged`（菜品变更）
  - `OrderChanged`（点餐变更）

## 7. 前端页面设计（微信小程序）

### 7.1 页面结构
```
pages/
├── index/                 # 首页（今日点餐）
├── menu/                  # 菜品列表
├── dish-edit/             # 新增/编辑菜品
├── history/               # 历史记录
├── family/                # 家庭管理（邀请码、成员）
```

### 7.2 主要页面说明

**首页（今日点餐）**
- 显示今日已点菜品列表
- 快速添加菜品按钮
- 实时更新
- 底部 Tab：今日点餐 | 菜单 | 我的

**菜单页**
- 分类 Tab（全部 / 早餐 / 午餐 / 晚餐）

- 显示邀请码（可复制/生成二维码）

- 使用 **Vant Weapp** 组件库（按钮、列表、弹窗、Tab、搜索等）
- 主色调：温暖橙色 / 浅绿色（家庭感）

## 9. 关键实现要点

### 9.1 登录流程
1. 小程序调用 `wx.login` 获取 code
2. 后端用 code 换取 openid（需配置小程序 AppId + AppSecret）
3. 查找或创建用户，生成 JWT 返回
4. 后续请求 Header 携带 `Authorization: Bearer {token}`

### 9.2 SignalR 鉴权
- 使用 JWT 认证
- 连接成功后根据用户的 FamilyId 加入对应 Group

### 9.3 SQLite 注意事项
- 开发时使用文件数据库（`family.db`）
- 生产环境注意文件权限与备份
- EF Core 迁移正常使用

### 9.4 图片处理（可选）
- 初期可不支持图片，或使用 base64 临时方案
- 后期可接腾讯云 COS / 阿里云 OSS

## 11. 部署建议

**推荐方案（长期免费）：**
1. Oracle Cloud Always Free（Arm 实例）
2. 安装 .NET 10 Runtime
3. 使用 Caddy 或 Nginx 反向代理 + 自动 HTTPS
4. 将 SQLite 文件放在安全目录并定期备份

**备选：**
- 微信云托管（.NET 容器）
- Render 免费层（有休眠）
